# YASB 设置

个人使用的 YASB 设置，个人备份，兼共享

## 示例图

<img width="1919" height="46" alt="example" src="https://github.com/user-attachments/assets/aabbb6cf-8fb8-4fef-a3b1-a438195cf991" />

从左、中、右顺序分别为：

| 左 | 中 | 右 |
| :---: | :---: | :---: |
| 固定在最左侧的文件夹，可自定义<br>当前打开的软件，鼠标右击可关闭<br>【有音频时触发】播放器窗口 | 日期加时间 | cava组件<br>系统托盘<br>内存占用情况<br>搜索<br>关闭、重启、注销、切换用户等 |

以上所有内容均可自行在配置文件中自定义

## 使用方法

将本仓库内的 `config.toml`、`styles.css`下载拖拽覆盖原配置文件，或选择性复制粘贴至配置文件内，保存，若未自动重载则右键YASB，手动 `Reload YASB`重载配置
